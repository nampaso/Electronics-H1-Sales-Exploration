# Duka Electronics Sales Exploration (Jan–Jun 2026)

## Project Summary
This project analyzes 1,000 sales transactions from Duka Electronics covering the first half of 2026 across five primary Kenyan branches. Using pandas and openpyxl, the analysis provides leadership with strategic insights on branch performance, product mix dynamics, channel distributions, and time-based purchasing behavior.

## Questions Answered
1. **Branch Rankings:** Do branch rankings by revenue match their order count rankings?
2. **Product Performance:** What are the top products by revenue vs. units sold, and what explains the variance?
3. **Sales Channels & Timing:** How do weekday vs. weekend transaction patterns compare across sales volume and ticket size?
4. **Seasonality:** Which month yielded peak revenue performance, and how does it compare to the lowest month?
5. **Target Filtering:** What is the combined performance of Premium Online sales in Nairobi and Mombasa?
6. **Cross-Platform Reconciliation:** Do Excel `SUMIFS`, `XLOOKUP`, and PivotTable outputs match Python pandas totals exactly?
